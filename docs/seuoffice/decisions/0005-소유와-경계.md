# 0005 소유와 경계

- 날짜: 2026-11-08
- 상태: 확정. 공개 여부는 0007이 대체
- 결정한 사람: 스풋

## 맥락

seuoffice는 유유헬스케어 업무(메신저 첨부 보기)에서 출발했다. 유유 저장소 규칙상 범용 모듈을 다른 고객에 쓰려면 유유 서면 동의가 필요하므로, 소유와 경계를 문서로 남긴다.

## 결정

- seuoffice는 스풋(GitHub SeuPut0705)의 개인 자산이다. 전부 스풋 개인 시간과 비용으로 만든다. 유유 계약 산출물이 아니며, 유유헬스케어는 사용자다.
- 저장소는 비공개로 둔다. 공개 여부는 1단계(웹 읽기 모드) 뒤 다시 정한다. 비공개 동안 유유 배포는 읽기 토큰으로 받는다.
- 유유헬스케어 저장소(`yuyuhealthcare/yuyu-mos`)의 코드, 설정, 데이터를 가져오지 않는다. 유유 실데이터와 고객 원본 문서도 넣지 않는다. 시험은 모의 문서나 권리가 확인된 문서로 한다.
- 유유 업무 앱과 연결하는 코드는 yuyu-mos 쪽에 둔다. seuoffice는 "바이트 + 파일 이름 → 화면" 부품과 정적 웹 묶음을 내놓는다.

## 버린 대안

- 유유 계약 시간으로 만들기: 결과물이 유유 자산이 되어 다른 곳에 쓸 수 없다.
- 지금 공개: 1단계 결과를 보고 정한다.

## 결과

- README "소유와 경계" 절과 AGENTS.md "경계" 절에 같은 내용을 둔다.
- 공개 권리가 확인되지 않은 시험 문서는 저장소 밖 비공개 폴더에만 둔다.

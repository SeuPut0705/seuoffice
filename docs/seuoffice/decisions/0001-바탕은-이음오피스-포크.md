# 0001 바탕은 이음오피스 포크

- 날짜: 2026-11-08
- 상태: 확정
- 결정한 사람: 스풋("저장소를 통째로 가져와 웹에서도 돌게 개조한다", 바탕은 측정 근거로 고른다)

## 맥락

seuoffice는 웹과 PC에서 문서를 보고 고치고 AI로 편집하는 오피스다. 출발점 후보는 GenOffice(https://github.com/genspark-ai/genoffice)와 그 한국어 포크 이음오피스(https://github.com/pblsketch/ieumoffice)였다. 둘 다 Electron 데스크톱 앱이고, 측정은 `../웹-전환-측정.md`에 있다.

## 결정

이음오피스 `aea1414`를 통째로 포크해 바탕으로 삼는다. 근거:

- GitHub상 GenOffice의 포크다(merge-base `438d9c65`, 이음이 2,422 커밋 앞서고 338 뒤짐).
- 제작사 연결과 분석 제거가 끝나 있다(`npm run check:no-genspark`).
- 한글 편집기(`apps/hwp`)와 rhwp 패치판이 있다. 공개 샘플 13건 비교에서 패치판이 npm 0.8.7보다 한컴에 가깝다(평균 8.07 vs 9.13).
- `ee/`(GenOffice Enterprise License)는 두 저장소 역사 전체에서 `LICENSE`·`README.md`뿐이고 이음 HEAD에는 없다.
- 1단계 다섯 형식 앱의 preload 브리지 호출 수는 이음 624, GenOffice 522다. 차이 약 20%는 한글 앱 몫이고, GenOffice는 한글을 열기만 한다.

## 버린 대안

- GenOffice 직접 포크: 한글은 hwp2docx 변환으로 열기만 되고 저장이 없다. 분석(GA)과 제작사 로그인·프로젝트 연결을 다시 걷어내야 한다.
- 부품만 가져오기(보기 라이브러리 조합): 스풋 지시로 버렸다. 결정 0003 참고.

## 결과

- 상위 원격 `ieum`(바탕)과 `genoffice`(원본)를 둔다. 따라가기는 결정 0006.
- 내부 이름은 `@genoffice/*` 그대로 둔다(결정 0002).
- 저장소 크기가 커진다(이음 약 219MB).

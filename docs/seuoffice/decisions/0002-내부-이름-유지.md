# 0002 내부 이름 유지

- 날짜: 2026-11-08
- 상태: 확정
- 결정한 사람: 메인 세션 판단, 스풋 변경 가능(2026-11-08 d5에서 유효로 확정)

## 맥락
들여온 트리는 패키지 범위 `@genoffice/*`, 환경 변수 `GENOFFICE_*`, 명령 `genoffice`, 사용자 폴더 `~/.genoffice`를 쓴다. 이음오피스도 이 이름을 바꾸지 않았다.

## 결정
- 내부 이름 `@genoffice/*`, `GENOFFICE_*`, `genoffice` 명령, `~/.genoffice`는 그대로 둔다.
- 사용자에게 보이는 이름, 설치본, 창 제목, 새로 만드는 공개 부품은 seuoffice / `@seuoffice/*`로 한다.
- 상위 추적을 끊기로 할 때 한 번에 개명한다.

## 버린 대안
- 지금 전부 개명: 상위(이음) merge 때마다 거의 모든 import와 package.json이 충돌한다. 따라가기 비용이 개명 이득보다 크다.

## 결과
- 새 패키지는 `packages/web-platform`(`@seuoffice/web-platform`), `packages/embed`(`@seuoffice/embed`), `apps/web`(`@seuoffice/web`)이다.
- 사용자에게 보이는 제품명 변경은 4단계(Windows 배포)에서 한다.

# 0006 상위 따라가기

- 날짜: 2026-11-08
- 상태: 확정

## 맥락

이음오피스는 계속 바뀐다(커밋 3,339개, GenOffice에서 2,422 앞섬). seuoffice는 이음 개선을 받으면서 웹 층을 더해야 한다.

## 결정

- 원격 둘을 둔다. `ieum` = https://github.com/pblsketch/ieumoffice(바탕), `genoffice` = https://github.com/genspark-ai/genoffice(원본).
- 이음은 merge로 따라간다. `git fetch ieum` → 가지 `sync/ieum-YYYYMMDD`에서 `git merge ieum/main` → 충돌 처리 → 합치기 전 검사 → `main`에 `--no-ff`. 루트 `AGENTS.md`, `CLAUDE.md`, `README.md`는 우리 것을 둔다.
- GenOffice는 보통 이음을 거쳐 받는다. 직접 받을 때는 이음 `docs/operations.md` "원본의 개선 받아오기" 절차대로 엔진 폴더 커밋만 `git cherry-pick -x`하고 `npm run check:no-genspark`를 돌린다.
- GenOffice `ee/`는 가져오지 않는다. `seuoffice` CI가 추적 파일에 `ee/`가 생기면 실패한다.
- 상위 파일을 고친 것은 모두 `../upstream-edits.md`에 적는다.

## 버린 대안

- 원본 GenOffice를 통째로 merge: 이음이 걷어낸 제작사 연결과 분석이 다시 들어온다.
- 상위 추적을 끊고 독립: 이음의 한글·AI 개선을 받기 어렵다. 끊을 때는 결정 0002에 따라 내부 이름을 한 번에 개명한다.

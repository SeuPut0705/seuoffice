# 웹 차이 목록

웹 브리지가 데스크톱과 다르게 동작하는 메서드를 적는다. 기본값을 돌려주거나 `WebUnsupportedError`로 거절하는 것이 모두 여기에 들어간다.

| 앱   | 브리지 메서드                                                                                                                                                                                  | 웹 동작                                                                                                                          | 데스크톱 동작                                                                            | 언제 메울지                                |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------ |
| pdf  | `getTheme`                                                                                                                                                                                     | 늘 `'system'`                                                                                                                    | 사용자가 고른 테마                                                                       | 2단계(호스트가 테마를 넘김)                |
| pdf  | `getAiPanelPrefs`, `getAiSettings`                                                                                                                                                             | 기본값(`DEFAULT_AI_PANEL_PREFS`, `defaultAiSettings()`)                                                                          | 사용자 설정 파일                                                                         | 3단계                                      |
| pdf  | `getAutoSaveDefault`                                                                                                                                                                           | 자동 저장 끔                                                                                                                     | 셸 설정                                                                                  | 2단계                                      |
| pdf  | `getUsername`                                                                                                                                                                                  | 빈 문자열(메모 작성자 없음)                                                                                                      | OS 사용자 이름                                                                           | 2단계(호스트 사용자 이름)                  |
| pdf  | `listEditFonts`, `listStaticFormFills`, `listDigitalSignatures`                                                                                                                                | 빈 목록                                                                                                                          | 시스템 글꼴, 파일 옆 기록, 서명 검사                                                     | 2단계                                      |
| pdf  | `isUntitledCopy`, `recoveryState`, `reportUnprotectable`, `imageGenerationAvailable`                                                                                                           | `false` / 복구 없음 / `null` / `false`                                                                                           | 셸 상태                                                                                  | 2·3단계                                    |
| pdf  | `setDirty`, `on*`(메뉴·셸 요청, 설정 변경 알림)                                                                                                                                                | 아무 일도 하지 않음                                                                                                              | 셸 창과 메뉴 연결                                                                        | 2단계                                      |
| pdf  | `structure`, `store`, `subscription`, `noteOpen`                                                                                                                                               | 없음(`undefined`, 기능 꺼짐)                                                                                                     | 문서 구조 분석, 번역 저장소, 구독 연결, 노트 앱                                          | 3단계                                      |
| pdf  | `decryptPdf`                                                                                                                                                                                   | `WebUnsupportedError('pdf.decrypt')`(암호 PDF는 앱의 암호 안내까지만)                                                            | 암호 해제                                                                                | 2단계                                      |
| pdf  | `save`                                                                                                                                                                                         | `WebUnsupportedError('pdf.save')`                                                                                                | 파일 저장                                                                                | 2단계                                      |
| hwp  | `beginSave`, `commitSave`, `newTabs`, `recoveryNewTabs`, `recoveryWrite`                                                                                                                       | `WebUnsupportedError('hwp.save')`                                                                                                | 저장 대화상자, 탭 폭 보정, 원자적 쓰기, 복구본 저장                                      | 2단계                                      |
| hwp  | `printPages`                                                                                                                                                                                   | `WebUnsupportedError('hwp.print')`                                                                                               | 인쇄 대화상자와 PDF 내보내기                                                             | 2단계                                      |
| hwp  | `aiStream`                                                                                                                                                                                     | `WebUnsupportedError('hwp.ai')`                                                                                                  | 앱 안 AI 도우미 스트리밍                                                                 | 3단계                                      |
| hwp  | `aiSubscription`, `pickAttachments`, `addAttachmentPaths`, `addPastedImage`, `readAttachment*`, `analyzeMedia`, `readUrl`, `imageSearch`, `generateImage`, `fetchImage`, `openAiModelSettings` | 없음(`undefined`, 기능 꺼짐)                                                                                                     | 첨부, 웹 검색, 이미지 생성, 구독 연결                                                    | 3단계                                      |
| hwp  | `recoveryBegin`, `recoveryOpened`                                                                                                                                                              | 복구 없음(`{ok:false}`, `{restored:false}`)                                                                                      | 비정상 종료 복구본                                                                       | 2단계                                      |
| hwp  | `getAuthorName`, `getAiSettings`, `getAiPanelPrefs`, `getAutoSaveDefault`                                                                                                                      | 빈 작성자, 상위 기본값                                                                                                           | 설정 파일 값                                                                             | 3단계                                      |
| hwp  | `readFile`                                                                                                                                                                                     | 추적 변경만 걷어내고 구역 꼬리·필드 종류 기록(`sectionTailsOf`, `fieldKindsOf`)은 건너뜀                                         | 저장 보정용으로 기록                                                                     | 2단계(저장을 넣을 때 `open-hwp.ts`에 추가) |
| hwp  | (스튜디오 글꼴)                                                                                                                                                                                | 옛한글 글꼴 `RHWPOldHangul-Regular.woff2`가 묶음에 없어 내려받기 실패, 옛한글은 대체 글꼴                                        | 같은 스튜디오 빌드                                                                       | 2단계                                      |
| docs | `getRecentFiles`, `getAuthorName`, `getAiSettings`, `consumeNewBlankDoc`, `consumeAiDocContent`, `consumeDocCopy`                                                                              | 빈 목록, 빈 이름, 상위 기본 AI 설정, false 또는 null                                                                             | 최근 파일, 사용자 이름, 저장된 AI 설정, 새 문서 대기 항목                                | 2단계                                      |
| docs | `fontMetrics`, `fontFamilyInfo`                                                                                                                                                                | null과 빈 목록(호스트 글꼴 파일을 읽지 못함)                                                                                     | 설치 글꼴의 세로 메트릭과 한글 정보                                                      | 3단계                                      |
| docs | 디자인 템플릿 글꼴 12종(`registerTemplateFonts`)                                                                                                                                               | 등록하지 않음(웹 설정이 `main.tsx`의 `./template-fonts`를 빈 대체 모듈로 바꾼다). 이 글꼴을 지정한 문서는 대체 글꼴로 그려진다   | 약 52MB 글꼴을 자체 URL 스킴으로 등록                                                    | 2단계                                      |
| docs | `fetchImage`                                                                                                                                                                                   | `fetch`로 받음(웹 CSP가 같은 출처, blob, data만 허용해 외부 주소는 null)                                                         | 메인 프로세스가 외부 이미지를 받아 base64로 줌                                           | 3단계                                      |
| docs | `openDocxDecrypt`, `setDocPassword`, `docPasswordIntentRevision`, `discardDocPasswordIntents`                                                                                                  | 암호 문서는 열기 오류(`open_failed`)로 거절, 해독과 암호 설정은 `WebUnsupportedError('docs.decrypt')`, 암호 의도 조회는 0과 성공 | 암호 OOXML을 해독해 열고 저장 때 다시 암호화                                             | 2단계                                      |
| docs | `saveDocx`, `saveDocxAs`, `saveDocxNew`, `saveDocxTo`, `materializeDocx`                                                                                                                       | `WebUnsupportedError('docs.save')`                                                                                               | 문서를 디스크에 저장                                                                     | 2단계                                      |
| docs | `convertAltChunkHtml`, `kbList`, `aiToolCapabilities`, `onMcpCommand`, `reportMcpResult`, `signalMcpReady`                                                                                     | 없음(`undefined`, 기능 꺼짐)                                                                                                     | HTML 조각 변환, 지식베이스 목록, AI 도구 기능, MCP 명령 연결                             | 3단계                                      |
| docs | `projectApi`(`loadChat`, `appendChat`, `resolveChat`, `rebindChat`)                                                                                                                            | `WebUnsupportedError('docs.project-chat')`(호출부가 오류를 삼킨다)                                                               | 문서별 AI 대화 기록 읽기와 쓰기                                                          | 3단계                                      |
| docs | `aiOfficeDriveAi`, `aiOfficeOutbound`, `aiOfficeMcpTools`, `aiOfficeUserSkills`, `aiOfficeDocs`, `aiOfficeSubscription`, `aiOfficeSplit`, `projectFolderApi`                                   | 부팅과 열기에서 쓰는 멤버를 `undefined`로 둠(기능 꺼짐)                                                                          | 셸이 드라이브 AI, 외부 도구, 사용자 기술, 문서 선택, 구독, 분할 창, 프로젝트 폴더를 제공 | 3단계                                      |

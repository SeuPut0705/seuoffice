# 웹 전환 측정 (2026-11-08)

측정일 2026-11-08. 대상은 GenOffice `0ac588f`(https://github.com/genspark-ai/genoffice)와 이음오피스 `aea1414`(https://github.com/pblsketch/ieumoffice)의 읽기 전용 복제다. 방법: 줄 수는 시험 파일을 뺀 `.ts`/`.tsx`/`.mjs`에 `find | xargs wc -l`, 브리지 표면은 앱별 `grep -c ipcMain`과 preload의 `ipcRenderer.*` 호출 수, 포크 관계·커밋 수·저장소 크기는 GitHub API, 앱별 열기 경로는 scout 추적으로 쟀다. `[추론]` 표시가 없는 항목은 관찰이다.

## 공개 패키지

- `@rhwp/core` 0.8.7 (MIT, npm 공개, 12.5MB unpacked): 브라우저용 Rust+WASM 파서·렌더러. `init(wasmUrl)` 후 `new HwpDocument(bytes)`, `renderPageSvg(n)` / `renderPageToCanvas(n, canvas, scale)`. HWP·HWPX 둘 다. README 빠른 시작이 vite + `public/rhwp_bg.wasm` 방식 (관찰: `npm pack` 후 README·rhwp.d.ts 읽음).
- `@rhwp/editor` 0.8.7 (MIT): iframe 임베드 편집기, studioUrl HTTP(S) origin만.
- npm 최신: docx-preview 0.4.1 Apache-2.0, pdfjs-dist 6.5.438 Apache-2.0, xlsx(SheetJS CE npm판) 0.18.5 Apache-2.0, exceljs 4.4.0 MIT, @univerjs/core 1.4.0 Apache-2.0 (GenOffice는 0.25.1 고정), canvaskit-wasm 0.42.0 BSD-3.

## 한글 저장 경로 (이음 `apps/hwp`)

- 바이트는 스튜디오 iframe의 rhwp가 만든다: `App.tsx:109–111` `editor.exportHwp()` / `exportHwpx()`, HWP는 `exportHwpVerify`(자기 재로드·쪽수 검증, `rhwp.d.ts:574`). 형식 자동 변환 없음(`.hwp`→HWP, `.hwpx`→HWPX, `save-as-formats.ts`).
- 메인은 검증·보정·쓰기만: `MAX_HWP_SAVE_BYTES` 512MiB(`src/shared/ipc.ts:148`), `save-plan.ts` `bytesMatchFormat`(ZIP/OLE 매직), `save-fixes.ts` `applySaveFixes` = `writeTabWidths` → (hwp만) `restoreFieldKinds` → (hwp만) `restoreSectionTails`, 세션 첫 덮어쓰기 `.bak`, `atomicWriteFile`(electron-utils, Node fs).
- 보정 모듈(`save-fixes.ts`, `tab-widths.ts`, `section-tails.ts`, `field-kinds.ts`, `tracked-changes.ts`, `memos.ts`, `save-plan.ts`)은 Buffer+`cfb`만 쓰는 순수 TS(AGENTS.md "Electron 없이 node에서 돈다") → 브라우저 이식 가능(Buffer shim).
- 거절: 암호 문서 저장, `ENCRYPTED|DISTRIBUTION`·ViewText(`hwp5-file.ts:14–17,71–75`). HWP3 저장 경로 없음.
- 알려진 손실: 수정한 바탕쪽 미저장(findings.md:636–639), 각주 `userChar`+`suffixChar` 중 하나 소실(findings.md:206–209), 저장 바이트≠원본(스트림은 같음, findings.md:833–839). 한컴 한글에서 다시 열리는지 자동 확인 없음.
- 왕복 자동 시험 없음(열기→같은 형식 저장→다시 열기→글자·쪽수 비교). 픽스처 약 40개(`apps/hwp/tests/fixtures/`). GenOffice `hwp2docx`는 열기 전용(HWP→HWPX→DOCX), 저장 없음.

## 비교 시험 REPORT.md 요점 (참고만)

- `<비공개 폴더>/doc-viewer/phase1/REPORT.md`: HWP는 이음 패치판 rhwp가 공개 샘플 13건에서 npm 0.8.7보다 한컴에 가깝다(평균 8.07 vs 9.13). PPTX는 GenOffice `pptx-engine`+`pptx-render`가 기준에 가장 가깝다. PDF는 pdf.js가 맞고, 내장 뷰어는 sandbox iframe에서 막힌다. WASM 컴파일에는 운영 CSP `'wasm-unsafe-eval'`이 필요하다[추론]. 크기 제안: PDF 30MB, Office/HWP 20MB. 공개 HWP 샘플은 권리 미확인이라 비공개 폴더에만 둔다. 저장소에 넣지 않는다.

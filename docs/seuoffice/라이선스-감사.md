# 라이선스 감사 (2026-11-13)

결정 [0031](decisions/0031-라이선스-FSL.md)을 정하기 전에 출하하는 것 전부를 라이선스로 훑은 기록이다. 원본은 하위 에이전트(scout) 두 개의 감사였고, 그 결과를 한국어로 옮기며 그 뒤에 고친 것을 함께 적는다. 막는 항목(비상업 전용, 독점, 재라이선스 금지)은 하나도 없었다. 아래 "처리"는 0031의 "스풋 판단, 외부 검토 없음"에 따른 보수적 기본값이다.

## 무엇이 출하되는가

- 데스크톱 설치본: `LICENSE.txt`, `LICENSE-APACHE.txt`, `NOTICE.txt`, `LICENSE-UNICODE.txt`, 만들어 넣는 `THIRD-PARTY-NOTICES.txt`(`tools/gen-third-party-notices.mjs`, 글꼴 저작권과 OFL 전문 포함), 편집기 묶음(`modules/*`), `template-fonts/`, `builtin-skills/`, `wasm/rhwp_bg.wasm`, 아이콘.
- 웹 묶음(`@seuoffice/web` tarball): `dist`(다섯 편집기와 그 글꼴·아이콘, `template-fonts/`, 옛한글 글꼴과 그 OFL), `LICENSE`, `LICENSE-APACHE`, `NOTICE`, 그리고 이번에 더한 `THIRD-PARTY-NOTICES.txt`.
- npm 묶음 `@seuoffice/embed`, `@seuoffice/collab`: 글꼴·그림 없음.
- 출하하지 않는 것: `docs/**`, `e2e/**`, 시험 자료, `tools/ooxml-validate/schemas`.

## npm 의존성

- 게이트: `tools/check-licenses.mjs`가 lock의 출하 패키지마다 허용 목록(`tools/license-allowlist.mjs`)을 본다. 둘 중 하나를 고르는 라이선스는 허용적인 쪽이 목록에 있으면 지난다.
- 고른 쪽은 `THIRD-PARTY-NOTICES.txt`에 적는다: jszip은 MIT, node-forge는 BSD-3-Clause, dompurify는 Apache-2.0, r-efi는 MIT. node-forge 줄은 이번에 더했다.
- `@univerjs/telemetry`(Apache-2.0)와 `khroma`(MIT)는 패키지에 라이선스 파일이 있어 그것을 근거로 수동 예외에 둔다.
- Electron(Chromium)은 `LICENSES.chromium.html`을 함께 싣는다. canvaskit·pdfium·qpdf·pdf.js의 wasm 안 라이브러리는 생성기의 EMBEDDED 표와 각 패키지의 LICENSE 파일로 싣는다.

## Rust

- 출하하는 그래프 셋(xlsx 사이드카, 그 WASI 빌드, wasm32로 빌드한 rhwp)은 CI `rust-licenses` 작업이 뿌리 `deny.toml`(licenses, bans)로 본다. 셋 다 예외 없이 지난다(rhwp의 IJG는 허용 목록에 근거와 함께 있다).
- `crates/`(Rust 가지)는 `crates/deny.toml`로 본다. ureq 쪽 네이티브 전용 시험 의존성(ring, rustls-webpki, untrusted, webpki-roots)은 그 파일에 크레이트별 예외가 있다.

## Rust 가지: 가지 주인에게 남김

`crates/file-parse/Cargo.toml`만 `[[package.metadata.notices.ported]]`로 옮겨 적은 원본을 선언한다(word-extractor MIT, ppt-to-text Apache-2.0, cfb Apache-2.0, yauzl MIT, fast-xml-parser MIT). 다음 크레이트도 다른 코드를 옮겨 적었는데 선언이 README나 설명에만 있다. 합치기 전에 같은 표로 선언하고 고지에 넣어야 한다.

| 크레이트      | 옮겨 적은 원본                                                       | 가지                                          |
| ------------- | -------------------------------------------------------------------- | --------------------------------------------- |
| `ooxml-xml`   | fast-xml-parser 5.10.1(MIT), 이 저장소의 TS `scan.ts`·`xml-utils.ts` | `feat/rust-fileparse-d3`, `feat/rust-pptx-c2` |
| `ooxml-pkg`   | JSZip 3.10.1(MIT 또는 GPL-3.0, MIT로 씀), `packages/zip-gate`        | 같음                                          |
| `saxes`       | saxes 6.0.0(ISC)                                                     | `feat/rust-fileparse-d3`                      |
| `epub-engine` | 이 저장소의 TS `packages/epub-engine`                                | `feat/rust-fileparse-d3`                      |

`docx-engine`, `pptx-engine`, `omml`은 같은 이름의 TS 패키지를 옮겨 적은 것이라 NOTICE의 GenOffice·이음오피스 고지 아래 있다(결정 0024).

`crates/mtx`(MPL-2.0, libeot 이식)는 MPL 3.2에 따라 소스 위치를 고지에 적고 PATENTS 파일을 함께 싣는다. 생성기의 "8. Third-party source code" 절이 이미 그렇게 한다.

## vendor

- `vendor/rhwp-core`: rhwp MIT. 패치 44개는 MIT 코드의 파생이고 rhwp 고지 아래 있다. wasm 안의 Latin Modern Math 윤곽(GUST Font License)과 DejaVu 포함 여부는 `vendor/rhwp-core/THIRD_PARTY_LICENSES.md`에 적혀 있다.
- `vendor/drawio`: 본체 Apache-2.0. 모양·스텐실·그림에 붙은 Atlassian 사용 제한 문구는 원문 그대로 `THIRD-PARTY-NOTICES.txt` 7절에 싣고 지킨다. ELK(EPL-2.0)는 잘라내고, libavoid(LGPL-2.1)·PlantUML·Glyphicons(CC BY 3.0)는 뺀다(`tools/check-drawio-bundle.mjs`가 막는다). 템플릿 CC-BY-4.0은 출처 표시를 싣는다.
- `emf-converter`: Apache 4(b) 변경 고지가 README에 있고 그대로 싣는다.

## 스킬과 자료

- 내장 스킬: 출처·커밋·라이선스가 `builtin-skills.json`에 있고 폴더마다 LICENSE가 있다. docx·pptx·xlsx·pdf 스킬 안의 ECMA·ISO·Microsoft 스키마는 upstream(anthropics/skills)이 싣는 그대로 싣고 `tools/asset-licenses.json`에 따로 적는다.
- 한자 사전(libhangul `hanja.txt`, BSD-3-Clause): 고지 원문을 곁에 쓰고 NOTICE에 싣는다.
- 유니코드 자료: `LICENSE-UNICODE.txt`.

## 이름과 상표

- GenOffice·Genspark 로고나 글자 그림은 출하하는 그림에 없다.
- 화면과 글꼴 이름에서 GenOffice를 빼는 일은 `chore/remove-genoffice-branding`에서 했다. 법적 고지(LICENSE, NOTICE, 소스 파일의 저작권 줄, 변경 고지)와 사용자에게 보이지 않는 호환 이름(`old-names*`, XML 네임스페이스, `genoffice-app://`)은 그대로 둔다.

## 기여자

- 커밋 4758개: GenOffice 공개 이력(`438d9c657`까지) 917, 이음오피스 이력 3951(겹침 포함), seuoffice 고유 807.

## 다시 재려면

- npm: `npm run licenses`(허용 목록), `npm run notices`(고지 생성, CI에서는 빈 곳이 있으면 실패).
- Rust: `cargo deny --config deny.toml --manifest-path <Cargo.toml> check licenses bans`.
- 체크인한 자산: `node tools/check-asset-licenses.mjs`.
- GenOffice에서 남은 양: `git diff -M --numstat d2fe8ddaa origin/main`, 원본 줄 수는 `git grep -c '' d2fe8ddaa`.

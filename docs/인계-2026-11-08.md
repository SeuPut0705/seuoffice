# seuoffice 인계 (2026-11-08, yuyu-mos 메인 세션에서)

## 스풋 결정
- 범위: **전체 오피스(문서 편집 + AI)**, 웹과 PC 프로그램 둘 다.
- 소유: **스풋 개인 자산, 별도 저장소**. 유유헬스케어 저장소(`yuyuhealthcare/yuyu-mos`) 밖. 유유는 이 결과물을 가져다 쓰는 쪽.
- 출발점: 유유 메신저 안에서 첨부 문서(PDF·오피스·한글·글)를 보는 기능이 필요해서 나온 이야기. 변환 서버 없이 브라우저에서 그리는 방향.

이름: 제품·저장소·폴더 `seuoffice`, 패키지 범위 `@seuoffice/*`. 스풋 개인 자산. 저장소 https://github.com/SeuPut0705/seuoffice (비공개, 2026-11-08 생성, Apache-2.0 LICENSE로 시작 — 공개 여부·라이선스는 바꿀 수 있음).

## 아직 정하지 않은 것 (새 세션이 먼저 정할 것)
1. (정함) 저장소는 개인 계정 `SeuPut0705/seuoffice`, 지금은 비공개.
2. 공개로 바꿀지(오픈소스, Apache-2.0 이어받기) / 비공개 유지. 비공개면 유유 배포(Docker 빌드)가 패키지를 받을 접근 방법이 필요하다.
3. 바탕: GenOffice를 직접 포크 / 이음오피스를 포크 / 부품만 가져오기. 둘 다 Electron 데스크톱 앱이라 웹으로 옮길 때 Electron 메인 프로세스 의존(fs, IPC)을 얼마나 걷어내야 하는지가 가장 큰 미지수.
4. 계약: 유유 계약 시간·비용으로 만드는지. 유유 저장소 규칙상 범용 모듈을 다른 고객에 쓰려면 유유 서면 동의가 필요하다. 공급사 자산이면 그 경계를 문서로 남겨야 한다.

## 조사한 소스 (읽기 전용 복제)
- `/tmp/genoffice-research` — https://github.com/genspark-ai/genoffice , HEAD `0ac588f`(2026-11-08). 루트 Apache-2.0. **`ee/`는 GenOffice Enterprise License(개발·시험만, 운영은 계약 필요) — 쓰지 않는다.** 패키지는 `private: true`, npm에 없음(E404). 쓸 만한 부품: `pptx-render`(슬라이드 그리기), `docx-engine`, `xlsx-gateway`(숫자 서식), `hwp2docx`(속은 `@rhwp/core` 0.8.7, `hwp.ts`가 node fs로 wasm 경로를 읽음), `doc2docx`·`ppt2pptx`(옛 형식, ppt는 1단계로 아직 사용자용 아님).
- `/tmp/ieumoffice-research` — https://github.com/pblsketch/ieumoffice , HEAD `aea1414`(2026-11-08). GenOffice를 고친 한국판, Apache-2.0, `ee/` 없음. 한글 편집기 `apps/hwp` = `@rhwp/editor` 0.8.7 + canvaskit-wasm. `vendor/rhwp-core` = rhwp(MIT, https://github.com/edwardkim/rhwp) devel `7d06d5c7`에 한컴 2024 인쇄 대비 화면 배치 수정 30개(`patches/`, 대부분 상위 미반영). wasm 압축 전 18MB. 출처 고지는 그 저장소 NOTICE 참고.
- 그 밖 후보: hahnlee/hwp.js(Apache-2.0), @ohah/hwpjs, docx-preview(VolodymyrBaydalka/docxjs), pdf.js, SheetJS CE, ExcelJS.

## 유유 쪽과의 경계
- 유유 메신저에 보기를 연결하는 일(첨부 칩 → 보기 창, 권한 확인된 내려받기 경로로 바이트 전달)은 yuyu-mos 세션이 맡는다. seuoffice는 "바이트 + 파일 이름 → 화면" 부품을 내놓는다.
- 유유 실데이터·고객 원본 자료는 이 저장소로 가져오지 않는다. 시험은 모의 문서로.

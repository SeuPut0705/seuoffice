# TypeScript defects found by the C3 port

Each row is a defect of `packages/odt-engine/src` found while porting it. It
is reported to main and is not fixed here. "Rust" says what the port does: the
same as the TypeScript (a faithful port), or own keys only where the
TypeScript reads a member of `Object.prototype` (the workspace's rule since
the docx port: a table lookup answers for own keys only). A row the gate
shows has its entry in `tools/odt-diff/divergences.json`.

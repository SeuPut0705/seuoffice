# GenOffice のインストール

すべてのバージョンは、GitHub にあるプロジェクトの [Releases ページ](https://github.com/SeuPut0705/seuoffice/releases/latest) で公開されています。

## 自分のマシンに合わせてファイルを選ぶ

| プラットフォーム        | 要件                                 | ファイル                        |
| ----------------------- | ------------------------------------ | ------------------------------- |
| **Windows**             | Windows 10 以降、64 ビット Intel/AMD | `GenOffice-Setup-<version>.exe` |
| **Mac**、Apple シリコン | macOS 12 以降、M1 以降のチップ       | `GenOffice-<version>-arm64.dmg` |

Releases ページにあるそのほかのファイル（`.zip`、`.yml`、`.blockmap`）は、アプリ自身が更新に使うものなので、ダウンロードする必要はありません。古いバージョンは Releases ページにそのまま残っています。

## Windows で

1. Releases ページから `GenOffice-Setup-<version>.exe` をダウンロードします。
2. 実行します。インストーラーにはコード署名がないため、Windows が最初に青い「Windows によって PC が保護されました」というウィンドウを表示することがあります。**詳細情報** を選び、続いて **実行** を選びます。実際の文言は Windows のバージョンによって異なります。
3. インストーラーの指示に従って最後まで進めます。

GenOffice がスタートメニューに追加され、`.docx`、`.xlsx`、`.pptx`、`.pdf` などが登録されるので、ファイルをダブルクリックすれば開きます。

インストーラーには署名がないため、上の Releases ページからダウンロードしたものだけを実行してください。

## Windows がダウンロードやインストールを止めるとき

### Edge が「一般的にダウンロードされていません」と表示する

Microsoft Defender SmartScreen は、ダウンロードした人がまだ少ないファイルについて、このように警告します。ファイルを残す方法についての Microsoft の案内は次のとおりです。

1. Edge のダウンロード一覧（**Ctrl+J**）を開き、ファイルの横の **…** を押して **保存** を選びます。
2. 開いたウィンドウで **詳細表示** を押し、続いて **保持する** を押します。ファイルはダウンロード フォルダーに残ります。

このウィンドウには、ファイルが安全であると報告するボタンもあります。このボタンは Microsoft の報告ページ（`feedback.smartscreen.microsoft.com`）を開くだけで、ファイルは残りません。そのページを閉じ、代わりにウィンドウの **詳細表示** を押してください。

ウィンドウに **詳細表示** や **保持する** がないとき:

- 学校や会社が管理している PC では、管理者がこの警告を無視できないように設定できます（Edge のポリシー）。その場合、その PC ではだれもファイルを残せません。管理者にインストールか許可を頼んでください。
- 別のブラウザーで Releases ページからダウンロードしても、同じファイルが手に入ります。
- どちらでも解決せず、自分の PC である場合は、最後の手段として、Microsoft のダウンロードのトラブルシューティングの案内に示されているとおり、Microsoft Defender SmartScreen を一時的にオフにできます。Edge で **設定など (…) ▸ 設定 ▸ プライバシー、検索、サービス ▸ セキュリティ** を開いて **Microsoft Defender SmartScreen** をオフにし、ファイルをもう一度ダウンロードしたら、すぐにオンに戻します。オフの間は、Edge はダウンロードについても、フィッシング ページなどの危険なサイトについても警告しません。

### 「Windows によって PC が保護されました」というウィンドウが表示される

Microsoft Defender SmartScreen は、署名のないインストーラーを初めて見たときにこのウィンドウを表示します。**詳細情報** を押すと **実行** ボタンが表示されます。学校や会社が管理している PC では、管理者の設定によってこのボタンが表示されないことがあります。その場合は管理者に相談してください。

### スマート アプリ コントロールが止める

Windows 11 のスマート アプリ コントロールがオンのときは、署名のないインストーラーの実行が止められ、**詳細情報** からの手順も表示されません。Microsoft によると、1 つのアプリだけを許可する方法はなく、**Windows セキュリティ ▸ アプリとブラウザー コントロール ▸ スマート アプリ コントロールの設定** でスマート アプリ コントロールをオフにするしかありません。オフにすると、ほかのすべてのアプリに対するこの保護も外れます。最近の更新を適用した Windows では、Windows を再インストールしなくてもオンに戻せます。

## Mac で

macOS 12（Monterey）以降が必要です。Mac 版には Apple の開発者署名がないため、最初に開くときに macOS は、アプリにマルウェアが含まれていないことを検証できないと表示し、アプリを開きません。次の手順で、一度だけ許可します。

1. dmg を開き、`GenOffice.app` を **アプリケーション** フォルダーにドラッグします。
2. アプリケーション フォルダーから GenOffice を開きます。警告が出たら **完了** を押します。
3. **システム設定 ▸ プライバシーとセキュリティ** を開きます。下のほうにある、GenOffice がブロックされたという行の横の **このまま開く** を押し、Mac のパスワードを入力します。このボタンは、アプリを開こうとしてから 1 時間ほど表示されます。
4. もう一度表示されるウィンドウで **開く** を押します。以降は警告なしで開きます。

macOS 12 では、場所は **システム環境設定 ▸ セキュリティとプライバシー ▸ 一般** で、ボタンはそこにある **このまま開く** です。

「壊れているため開けません」と表示された場合は、ゴミ箱に移さないでください。下の 1 行を ターミナル で実行してから、もう一度アプリを開き、上と同じ手順で許可します。インターネットからダウンロードしたファイルに macOS が付ける印を外すコマンドです。

```sh
xattr -dr com.apple.quarantine /Applications/GenOffice.app
```

macOS が、このアプリはこの Mac ではサポートされていないと表示した場合は、**このMacについて**を確認してください。GenOffice は、macOS 12 以降を搭載した Apple シリコンの Mac（M1 以降のチップ）でのみ動作し、Intel Mac や macOS 11 以前では動作しません。

Mac ではほかにも次の点に注意してください。

- AI 接続のカードにはインストールボタンがありません。カードにある公式のインストールガイドのリンクに従って、Claude Code や Codex をインストールしてください。Claude デスクトップアプリは Claude Code ではないため、デスクトップアプリがあっても Claude Code は別にインストールする必要があります。
- サインインはブラウザーで完了します。ブラウザーでコードを貼り付けるよう求められたら、ターミナル で `claude auth login` または `codex login` をご自身で実行してください。[サブスクリプションの接続](help://subscription) を参照してください。

## 更新

- GenOffice は、同じ GitHub の Releases ページで新しいバージョンを探します。公開されると、**設定 ▸ 情報** に更新が表示されます。**… に更新する** を押してダウンロードが終わるのを待ち、**再起動してインストール** を押します。Windows ではインストールの進行状況ウィンドウが表示され、完了すると GenOffice が開いていた文書とともに再び開きます。Mac ではアプリが終了し、新しいバージョンに置き換わってから、開いていた文書とともに再び開きます。これは「アプリケーション」フォルダに置いたアプリの場合で、ディスクイメージから直接開いたアプリではダウンロードページが案内されます。更新はこのボタンを押したときだけインストールされ、アプリを閉じただけではインストールされません。
- **メニュー（☰） ▸ 更新を確認** を選ぶと、その場で確認します。Mac では **ヘルプ ▸ 更新を確認** です。
- 確認に失敗したとき（ネットワークがない、まだ何も公開されていないなど）は何も起こらず、アプリはそれまでどおり使えます。
- 更新にもコード署名はありません。インストールの前に、アプリはダウンロードしたファイルを、そのリリースと一緒に公開されたチェックサムと照合します。
- **再起動してインストール** を押してアプリが閉じたのに新しいバージョンにならなかった場合は、次に起動したときにそのことを知らせ、もう一度更新を勧めます。今度はインストーラーがウィンドウで開くので、進み具合を確認し、管理者の承認を求められたら答えられます。それでもうまくいかないときは、更新ウィンドウがダウンロードページを案内します。そこで入手したインストーラーで入れても、設定と文書はそのまま残ります。更新の経過はアプリのデータフォルダーの `update-log.txt` に記録されます（エクスプローラーのアドレスバーに `%APPDATA%\GenOffice` と入力すると開きます）。問題を報告するときはこのファイルを添えてください。

## いま動かしているビルド

**設定 ▸ 情報** は、お使いのバージョン、追随しているチャネル、プロジェクトが置かれている場所をアプリが示す場所です。このアプリのもとになったオープンソースプロジェクトの名前も、ここに記されています。

## コマンドラインも同梱されています

どのインストールにも `ieumoffice` コマンドが含まれ、ウィンドウと同じエンジンを動かします。そのため、同じファイルについて両者の結果が食い違うことはありません。`ieumoffice install-cli` で `PATH` に追加できます。何ができるかは [コマンドラインとエージェント](help://cli) を参照してください。

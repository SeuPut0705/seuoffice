# Установка GenOffice

Каждая версия публикуется на [странице релизов](https://github.com/SeuPut0705/seuoffice/releases/latest) проекта на GitHub.

## Выберите файл для своего компьютера

| Платформа              | Требования                                   | Файл                            |
| ---------------------- | -------------------------------------------- | ------------------------------- |
| **Windows**            | Windows 10 или новее, 64-разрядный Intel/AMD | `GenOffice-Setup-<version>.exe` |
| **Mac**, Apple Silicon | macOS 12 или новее, чип M1 или новее         | `GenOffice-<version>-arm64.dmg` |

Остальные файлы на странице релизов (`.zip`, `.yml`, `.blockmap`) приложение само использует для обновления; скачивать их не нужно. Более старые версии остаются на странице релизов.

## В Windows

1. Скачайте `GenOffice-Setup-<version>.exe` со страницы релизов.
2. Запустите его. У установщика нет цифровой подписи, поэтому Windows может сначала показать синее окно «Система Windows защитила ваш компьютер». Выберите **Подробнее**, затем **Выполнить в любом случае**. Точные формулировки зависят от версии Windows.
3. Пройдите установщик до конца.

Он помещает GenOffice в меню «Пуск» и регистрирует `.docx`, `.xlsx`, `.pptx`, `.pdf` и подобные форматы, так что двойной щелчок по файлу открывает его в GenOffice.

Поскольку установщик не подписан, запускайте только тот, который скачали со страницы релизов, указанной выше.

## Когда Windows блокирует загрузку или установку

### Edge пишет, что файл «нечасто скачивают»

Так Microsoft Defender SmartScreen предупреждает о файле, который скачивали немногие. Чтобы сохранить файл, Microsoft советует сделать следующее:

1. Откройте список загрузок Edge (**Ctrl+J**), нажмите **…** рядом с файлом и выберите **Сохранить**.
2. В открывшемся окне нажмите **Показать больше**, затем **Всё равно сохранить**. Файл останется в папке «Загрузки».

В этом окне есть и кнопка, которая сообщает, что файл безопасен. Она лишь открывает страницу отчётов Microsoft (`feedback.smartscreen.microsoft.com`) и не сохраняет файл. Закройте эту страницу и вместо этого нажмите в окне **Показать больше**.

Если в окне нет **Показать больше** или нет **Всё равно сохранить**:

- На компьютере, которым управляет школа или компания, администратор может запретить пропускать такие предупреждения (политика Edge). Тогда никто на этом компьютере не сможет сохранить файл; попросите администратора установить приложение или разрешить его.
- Если скачать файл со страницы релизов в другом браузере, получится тот же самый файл.
- Если ничего из этого не помогло и это ваш собственный компьютер, руководство Microsoft по устранению неполадок с загрузками допускает в крайнем случае ненадолго отключить Microsoft Defender SmartScreen. В Edge откройте **Настройки и прочее (…) ▸ Настройки ▸ Конфиденциальность, поиск и службы ▸ Безопасность**, выключите **Microsoft Defender SmartScreen**, скачайте файл ещё раз и сразу же включите защиту обратно. Пока она выключена, Edge не предупреждает ни о загрузках, ни об опасных сайтах, например фишинговых страницах.

### Появляется окно «Система Windows защитила ваш компьютер»

Microsoft Defender SmartScreen показывает это окно, когда впервые встречает неподписанный установщик. Нажмите **Подробнее**, и появится кнопка **Выполнить в любом случае**. На компьютере, которым управляет школа или компания, эту кнопку может скрыть параметр, заданный администратором; обратитесь к администратору.

### Установку блокирует Smart App Control

Когда в Windows 11 включён Smart App Control, он останавливает неподписанные установщики и не предлагает пути через **Подробнее**. По словам Microsoft, разрешить отдельное приложение нельзя: единственный вариант — отключить Smart App Control в разделе **Безопасность Windows ▸ Управление приложениями и браузером ▸ Параметры Smart App Control**. Это снимает защиту и для всех остальных приложений. В Windows с последними обновлениями его можно снова включить без переустановки Windows.

## На Mac

Нужна macOS 12 (Monterey) или новее. У сборки для Mac нет подписи разработчика Apple, поэтому при первом открытии macOS сообщает, что не может проверить приложение на наличие вредоносного ПО, и не открывает его. Это разрешается один раз, как описано ниже.

1. Откройте dmg и перетащите `GenOffice.app` в папку **Программы**.
2. Откройте GenOffice из папки «Программы». Когда появится предупреждение, нажмите **Готово**.
3. Откройте **Системные настройки ▸ Конфиденциальность и безопасность**. Внизу, рядом со строкой о том, что GenOffice заблокировано, нажмите **Всё равно открыть** и введите пароль от Mac. Кнопка видна примерно час после попытки открыть приложение.
4. В окне, которое появится снова, нажмите **Открыть**. После этого приложение открывается без предупреждения.

В macOS 12 это место — **Системные настройки ▸ Защита и безопасность ▸ Основные**, и кнопка там тоже **Всё равно открыть**.

Если macOS сообщает, что приложение «повреждено и не может быть открыто», не перемещайте его в Корзину. Выполните строку ниже в Терминале, затем снова откройте приложение и разрешите его, как описано выше. Она убирает метку, которую macOS ставит на файлы, скачанные из интернета.

```sh
xattr -dr com.apple.quarantine /Applications/GenOffice.app
```

Если macOS сообщает, что приложение не поддерживается на этом Mac, посмотрите **Об этом Mac**. GenOffice работает только на Mac с Apple Silicon (M1 или новее) под macOS 12 или новее; на Mac с процессором Intel и в macOS 11 и старше он не запускается.

Ещё о Mac:

- У карточек подключения ИИ нет кнопки установки. Чтобы установить Claude Code или Codex, перейдите по ссылке на официальное руководство по установке на карточке. Настольное приложение Claude не является Claude Code, поэтому Claude Code нужно установить отдельно, даже если настольное приложение уже есть.
- Вход завершается в браузере. Если браузер просит вставить код, сами выполните в Терминале `claude auth login` или `codex login`. См. [Подключение по подписке](help://subscription).

## Обновления

- GenOffice ищет более новую версию на той же странице релизов на GitHub. Когда она опубликована, её предлагает раздел **Настройки ▸ О программе**: нажмите **Обновить до …**, дождитесь загрузки, затем нажмите **Перезапустить и установить**. В Windows откроется окно с ходом установки; после неё GenOffice откроется снова вместе с документами, которые были открыты. На Mac приложение закрывается, заменяется новой версией и открывается снова вместе с открытыми документами. Так работает приложение из папки «Программы»; приложение, открытое прямо из образа диска, вместо этого покажет страницу загрузки. Обновление устанавливается только по этой кнопке, а не при обычном закрытии приложения.
- **Меню (☰) ▸ Проверить обновления…** выполняет проверку по вашему запросу. На Mac это **Справка ▸ Проверить обновления…**.
- Если проверка не удалась — нет сети или ещё ничего не опубликовано, — ничего не происходит, и приложение продолжает работать как прежде.
- У обновлений тоже нет цифровой подписи. Перед установкой приложение сверяет скачанный файл с контрольной суммой, опубликованной вместе с этим релизом.
- Если после **Перезапустить и установить** приложение закрылось, а новая версия так и не появилась, при следующем запуске приложение сообщит об этом и снова предложит обновление. На этот раз установщик откроется в отдельном окне: вы увидите ход установки и сможете ответить на запрос прав администратора. Если и это не поможет, окно обновления направит на страницу загрузки; установка из скачанного там файла сохраняет настройки и документы. Действия программы обновления записываются в `update-log.txt` в папке данных приложения (введите `%APPDATA%\GenOffice` в адресную строку Проводника, чтобы открыть её). Приложите этот файл, когда сообщаете о проблеме.

## Сборка, которую вы запускаете

**Настройки ▸ О программе** — место, где приложение сообщает, какая у вас версия, за каким каналом оно следит и где находится проект. Там же назван проект с открытым исходным кодом, на котором основано это приложение.

## Командная строка идёт в комплекте

Каждая установка включает команду `ieumoffice`, которая работает через те же движки, что и окно, поэтому они никогда не расходятся во мнении о файле. `ieumoffice install-cli` помещает её в ваш `PATH`. Что она умеет — см. [Командная строка и агенты](help://cli).

# FSL prep audit: fonts, images, templates, skills, data (non-code assets)

Scope: tracked assets at `chore/fsl-prep` (07a251652), plus build-time assets that ship but are not tracked (section D). Read-only: no git, no build. I had no shell, so I listed files with glob (gitignore respected, so every hit is tracked or at least not ignored) and read the evidence files. Test-fixture directories were not enumerated one by one; they are covered by directory globs in the JSON. Machine inventory: `local://fsl-asset-inventory.json` (first match wins; specific entries precede general ones).

Status counts: **fine 26, needs legal review 22, blocked 0.** Nothing I found is non-commercial or proprietary. The unresolved items are font naming (RFN), missing provenance for GenOffice-era images, and a few notice-delivery gaps.

How things ship (from `apps/shell/electron-builder.cjs`, `apps/web/scripts/build.mjs`, `apps/web/package.json`):
- Desktop extraResources: `LICENSE.txt`, `NOTICE.txt`, `LICENSE-UNICODE.txt`, generated `THIRD-PARTY-NOTICES.txt` (tools/gen-third-party-notices.mjs; carries font copyrights and the full OFL text), `modules/*` (renderer `out/` trees, so fonts, icons and textures are bundled), `template-fonts/` (whole `packages/ui/template-fonts`, so licence texts ship beside the fonts), `builtin-skills/` (whole folder), `cli/skills/seuoffice/SKILL.md`, `wasm/rhwp_bg.wasm`, Windows `shell-new/*.docx|xlsx|pptx`, per-type `.ico`, mac/win/linux icons from `apps/shell/build`.
- Web (`apps/web`, npm `files`: `dist`, `README.md`, `LICENSE`, `NOTICE`): all five suite apps (their fonts and icons), `template-fonts/` copied whole, old-Hangul font with its OFL text. `THIRD-PARTY-NOTICES.txt` is NOT in the web package (see X1).
- Other npm packages with `"private": false`: `packages/collab`, `packages/embed`. Neither holds font or image assets. `packages/ui` exports fonts but is private.
- No sounds, videos or audio ship. `e2e/assets/click-sequence-video.mp4` is a test input.
- Dev-only, not shipped: `tools/ooxml-validate/schemas` (NOTICE says so), `docs/**`, `e2e/**`, test fixtures.
